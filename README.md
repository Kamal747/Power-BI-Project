# 📊 Power BI Restaurant Analysis Project

## 🔍 Project Overview
This project focuses on analyzing restaurant data using **Power BI** to understand
patterns in **ratings, pricing, cuisines, and services**.  
The goal is to convert raw data into **interactive dashboards and meaningful insights**.

---

## 🎯 Objectives
- Analyze restaurant ratings across different price ranges  
- Identify whether higher-priced restaurants offer more services  
- Find popular cuisine combinations  
- Build interactive dashboards for easy exploration  

---

## 🛠 Tools & Technologies
- Power BI  
- Data Cleaning & Transformation  
- Basic DAX  
- Excel / CSV Dataset  

---

## 📂 Dataset Description
The dataset includes:
- Restaurant name  
- Ratings  
- Price range  
- Cuisines  
- Services offered  

Data was cleaned and transformed inside Power BI before visualization.

---

## 📈 Key Dashboards & Visuals
- Average rating by price range  
- Services vs pricing analysis  
- Cuisine popularity analysis  
- Interactive slicers and filters  

---

## 📌 Key Insights
- Higher-priced restaurants generally offer more services  
- Certain cuisines appear more frequently in combinations  
- Ratings vary significantly across price ranges
